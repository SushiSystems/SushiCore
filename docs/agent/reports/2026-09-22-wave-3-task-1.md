## Step 1: blocked — the plan's grep does not hold in this repository

The plan states the grep for `WORKSPACE_CLI_DIR` finds only SushiStack users, "measured
across all seven Sushi repositories on 2026-09-22", and instructs: "if this grep finds a use
inside sushicore itself, stop and report rather than inventing a replacement." It does:

`sushicore/module_config.py` imports `WORKSPACE_CLI_DIR` and uses it in
`_shared_config_local()` (line 107) to locate the workspace-shared `config.local.toml` that
`hub install` writes, which every module CLI (`sr`, `se`, `sa`, ...) layers through
`ModuleConfig.sources()` / `ModuleConfig.load()`. This is a real internal dependency, not a
false positive — deleting the constant without touching `module_config.py` would break the
import at module load time for every consumer of `ModuleConfig`.

Per the stop instruction, `WORKSPACE_CLI_DIR` was **not** deleted, and `module_config.py` was
**not** touched. That decision belongs to the plan owner: whether `module_config.py` should
resolve the shared config path through the new `sushistack`-owned `workspace_file()` (task 2's
interface) instead, whether `ModuleConfig` itself needs to change shape, or whether the
constant stays until that caller is rewired. I did not invent any of those answers.

Consequence: `sushicore` still exports `WORKSPACE_CLI_DIR`. Step 4's expectation (`hasattr(w,
'WORKSPACE_CLI_DIR') == False`) will not hold until this is resolved — flagging that now rather
than at release.

## Question for the owner

`config.local.toml` path once `WORKSPACE_CLI_DIR` is gone? Task 2 defines `workspace_file()` in
`sushistack.config`, owned by SushiStack, not `sushicore` — so `sushicore` cannot import it.
Options I see, none of which I picked: (a) `ModuleConfig` takes the shared-config path as a
constructor parameter from each CLI's profile instead of deriving it itself; (b) the constant
moves to each CLI's own profile/config module and is passed in; (c) something else. This
decides a public interface shape, which is not mine to choose.
