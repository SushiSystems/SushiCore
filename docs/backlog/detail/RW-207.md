# RW-207 Let pre-commit check the index while other files stay unstaged

The row of this entry is in `docs/backlog/CHECKERS.md`. This file holds what did not fit the row.

`refusal()` in `pre_commit.py` refuses a commit while any tracked file differs from the index, because
the checkers run in place on the disk copy. In a repository where several sessions work at once,
every commit then needs the others' work stashed and restored; on 2026-11-28 in SushiEngine two
such pops rewrote untracked files with CRLF and conflicted in the generated backlog summary. The
docstring of `run` says the hook checks the files the commit will hold, which the refusal only
approximates.
